tuios 0.13.0 is a big one, so I skipped 0.12.2 and gave it a new minor number. You can now move the daemon to a new build without ending a single pane, and the client on your machine follows it. You can write your own actions and change the right-click menus in `config.toml`. Frames are written as cells now, so a typed key costs about a fifth of what it did. Linking another machine is one command, `tuios hosts setup`. Agents get task boards with dispatch, and an agent can hand a task to a child agent and get the answer back by mail. Quick look reads much more, plugins get a full toolkit, and bash and zsh panes get prompt marks with no change to your files. [What's new](https://tuios.dev/docs/whats-new) has the short version, with a link to each page, and [Upgrading to v0.13.0](https://tuios.dev/docs/upgrading-to-v0-13-0) lists what to check.

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.13.0
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.13.0
```

A binary installed by the script or from an archive updates with `tuios update`. A v0.12.1 daemon cannot hand its panes over, so move it to the new build once with `tuios restart-server`. The restart stops the programs in your panes, and each session comes back with its layout, its pane history and new shells. From then on, `tuios daemon upgrade` moves the daemon to a new build and every program keeps running. See [Upgrading to v0.13.0](https://tuios.dev/docs/upgrading-to-v0-13-0). See [Upgrade in place](https://tuios.dev/docs/daemon-restart#upgrade-in-place).

## Highlights

- **Actions and menus of your own.** `[[actions]]` in `config.toml` declares an action:
  a built-in one, a program with the focused pane's folder or title as an argument, or
  a plugin action. Bind it to a key, find it in the command palette, run it with
  `tuios actions run`. `[menus.NAME]` is one table for every menu: the which-key panels
  and the right-click menus, where `add`, `after` and `remove` change the rows tuios
  ships. ([#2036](https://github.com/Gaurav-Gosain/tuios/pull/2036), [#2037](https://github.com/Gaurav-Gosain/tuios/pull/2037))
- **Faster frames.** The client writes each frame as cells and sends the terminal only
  what changed. With a typed key in a 200x60 window the frame went from 1023 us to
  205 us, and from 792 to 376 allocations. ([#2001](https://github.com/Gaurav-Gosain/tuios/pull/2001), [#2050](https://github.com/Gaurav-Gosain/tuios/pull/2050))
- **Live upgrade.** From this release on, `tuios daemon upgrade` moves a running daemon to a new binary without
  ending your panes, and `scripts/install.sh --upgrade-server` and `tuios hosts sync --restart` use it. A
  client on this machine follows the daemon across the upgrade and runs the new build too. ([#1858](https://github.com/Gaurav-Gosain/tuios/pull/1858), [#1333](https://github.com/Gaurav-Gosain/tuios/pull/1333), [#1398](https://github.com/Gaurav-Gosain/tuios/pull/1398), [#1480](https://github.com/Gaurav-Gosain/tuios/pull/1480), [#1593](https://github.com/Gaurav-Gosain/tuios/pull/1593), by
  @abhijit-s)
- **Set up a machine in one command.** `tuios hosts setup` links another machine step
  by step, asks for what it needs, picks tailnet machines from a list, and names an ssh
  failure with its fix. tuios offers to add a machine when a pane logs in to it with ssh.
  ([#1601](https://github.com/Gaurav-Gosain/tuios/pull/1601), [#1608](https://github.com/Gaurav-Gosain/tuios/pull/1608), [#1612](https://github.com/Gaurav-Gosain/tuios/pull/1612), [#1616](https://github.com/Gaurav-Gosain/tuios/pull/1616), [#1597](https://github.com/Gaurav-Gosain/tuios/pull/1597), [#1609](https://github.com/Gaurav-Gosain/tuios/pull/1609))
- **Task board.** The agents view shows the task board as kanban columns, with a card
  lifecycle, Ready to merge, project boards and auto dispatch. ([#1548](https://github.com/Gaurav-Gosain/tuios/pull/1548), [#1748](https://github.com/Gaurav-Gosain/tuios/pull/1748), [#1726](https://github.com/Gaurav-Gosain/tuios/pull/1726),
  [#1746](https://github.com/Gaurav-Gosain/tuios/pull/1746), [#1733](https://github.com/Gaurav-Gosain/tuios/pull/1733))
- **Child agents.** An agent can delegate a task to a child agent and get the answer
  back by mail. Children are linked to their parent, show in its thread, and their
  approvals and questions route to the person. ([#1565](https://github.com/Gaurav-Gosain/tuios/pull/1565), [#1574](https://github.com/Gaurav-Gosain/tuios/pull/1574), [#1575](https://github.com/Gaurav-Gosain/tuios/pull/1575), [#1576](https://github.com/Gaurav-Gosain/tuios/pull/1576), [#1562](https://github.com/Gaurav-Gosain/tuios/pull/1562))
- **Quick look reads much more.** Long files in windows, search and go to line, PDF
  pages, film strips, more file kinds, Markdown with HTML, alerts, footnotes and
  Mermaid, and copy mode over the preview. ([#1447](https://github.com/Gaurav-Gosain/tuios/pull/1447), [#1451](https://github.com/Gaurav-Gosain/tuios/pull/1451), [#1452](https://github.com/Gaurav-Gosain/tuios/pull/1452), [#1455](https://github.com/Gaurav-Gosain/tuios/pull/1455), [#1458](https://github.com/Gaurav-Gosain/tuios/pull/1458), [#1462](https://github.com/Gaurav-Gosain/tuios/pull/1462),
  [#1684](https://github.com/Gaurav-Gosain/tuios/pull/1684))
- **Plugins grow up.** `tuios plugins new`, `check`, `dev`, `update` and `stats`, the
  first-party plugins install from the release, a `ui` grant with dock cells, themes and
  screen savers as plugins, and a written plugin API. ([#1456](https://github.com/Gaurav-Gosain/tuios/pull/1456), [#1457](https://github.com/Gaurav-Gosain/tuios/pull/1457), [#1466](https://github.com/Gaurav-Gosain/tuios/pull/1466), [#1473](https://github.com/Gaurav-Gosain/tuios/pull/1473), [#1484](https://github.com/Gaurav-Gosain/tuios/pull/1484),
  [#1460](https://github.com/Gaurav-Gosain/tuios/pull/1460), [#1499](https://github.com/Gaurav-Gosain/tuios/pull/1499), [#1500](https://github.com/Gaurav-Gosain/tuios/pull/1500))
- **Prompt marks in bash and zsh.** tuios turns on OSC 133 marks in the shells it starts,
  without editing your files, so the scrollback browser, `tuios run` and copy mode know
  where each command starts and ends. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- **Drag and drop with the desktop.** Drags go to and from the desktop through kitty's
  drag and drop protocol. ([#1374](https://github.com/Gaurav-Gosain/tuios/pull/1374), [#1530](https://github.com/Gaurav-Gosain/tuios/pull/1530), by @dschmidt)

## Before you upgrade

- **Cell frames are the default.** The client writes frames as cells on every
  terminal you run tuios in, except on Windows, and on SSH and web clients. If the screen looks wrong, set
  `appearance.cell_frames = "off"` or start tuios with `TUIOS_CELL_FRAME=0`, and please
  tell me your terminal's name and version. ([#2001](https://github.com/Gaurav-Gosain/tuios/pull/2001))
- **One name per action.** Actions that had two or more names, such as
  `prefix_new_window` and `window_prefix_new` for `new_window`, have one name now. The
  older names still work in your config, presets, tapes and over the protocol, and
  `tuios keybinds list` shows them as "(also: ...)". A keybinding that names an action
  tuios does not know now gets a warning when the config loads. ([#2014](https://github.com/Gaurav-Gosain/tuios/pull/2014), [#1982](https://github.com/Gaurav-Gosain/tuios/pull/1982))
- **Usage limits have their own state.** An agent that stops on a usage or rate limit
  is `limit_reached` now, not `errored`. A script that waits for `errored` on a limit
  should look for `limit_reached`. ([#2059](https://github.com/Gaurav-Gosain/tuios/pull/2059))
- **Go-to holds the switchers.** The session switcher, the workspace switcher and the
  window list are now go-to, and pane rows show their folder. Every list takes the keys
  of `[keybindings.lists]`. ([#1989](https://github.com/Gaurav-Gosain/tuios/pull/1989), [#2012](https://github.com/Gaurav-Gosain/tuios/pull/2012))
- **Popups sit in the middle of the screen**, clear of the rail, and the agents view
  no longer dims the dock and the rail. ([#1839](https://github.com/Gaurav-Gosain/tuios/pull/1839), [#1844](https://github.com/Gaurav-Gosain/tuios/pull/1844))
- **The dock orders minimized panes by window order**, so dock pill N and restore N
  pick the same pane on every client. ([#1852](https://github.com/Gaurav-Gosain/tuios/pull/1852))
- **Hooks talk to the daemon directly.** Run `tuios integration install` again to get
  hook commands that send each event to the daemon socket with `nc -U` or `socat`, so a
  hook no longer starts a whole tuios. Without either program, nothing changes. ([#1908](https://github.com/Gaurav-Gosain/tuios/pull/1908),
  [#1918](https://github.com/Gaurav-Gosain/tuios/pull/1918), [#1919](https://github.com/Gaurav-Gosain/tuios/pull/1919))
- **One restart to get here.** The v0.12.1 daemon predates live upgrades, so run
  `tuios restart-server` once after you install. The next upgrade can be live.
- **Building from source** needs the Go 1.27.4 toolchain, which `go install` fetches
  for you. A plain `go install` binary is about 0.8 MB larger than the release, which
  turns inlining off in the cold packages. ([#1876](https://github.com/Gaurav-Gosain/tuios/pull/1876), [#2053](https://github.com/Gaurav-Gosain/tuios/pull/2053))
- The rarer Mermaid diagram types moved to the `sketch` plugin. Eight common types
  still draw in tuios. For the rest, run `tuios plugins install sketch`. ([#1467](https://github.com/Gaurav-Gosain/tuios/pull/1467), [#1505](https://github.com/Gaurav-Gosain/tuios/pull/1505))
- bash and zsh panes now get OSC 133 prompt marks. Set `[shell] integration = "off"`
  to start shells as before. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- The ghostty backend now uses libghostty-vt 1.0.1. Rebuild it with
  `scripts/install.sh ghostty`. ([#1775](https://github.com/Gaurav-Gosain/tuios/pull/1775), [#2009](https://github.com/Gaurav-Gosain/tuios/pull/2009))
- The binary size ceiling is now 50 MB. ([#1555](https://github.com/Gaurav-Gosain/tuios/pull/1555))

## Performance

- A typed key costs a row, not the screen: 1023 us to 205 us a frame. ([#2050](https://github.com/Gaurav-Gosain/tuios/pull/2050))
- With nine tiled panes under a flood, the client uses about a third less CPU with
  cell frames. ([#2001](https://github.com/Gaurav-Gosain/tuios/pull/2001))
- A change to a session nobody is attached to is not encoded: at 100 windows a publish
  went from 187 us to 1.34 us. ([#1967](https://github.com/Gaurav-Gosain/tuios/pull/1967), by @Gsirawan)
- A state push leaves the task cards' bodies out, so a session with about a thousand
  long cards attaches again. ([#1871](https://github.com/Gaurav-Gosain/tuios/pull/1871) by @Gsirawan, landed in [#1877](https://github.com/Gaurav-Gosain/tuios/pull/1877))
- A Done column of 2000 cards builds in 2.38 ms, not 91.55 ms. ([#2046](https://github.com/Gaurav-Gosain/tuios/pull/2046), by @Gsirawan)
- A full scrollback ring keeps each slot the size of its line, which cuts the memory
  of 50 panes with 100,000 lines from 1,208 MB to 711 MB. ([#1991](https://github.com/Gaurav-Gosain/tuios/pull/1991))
- The release binary turns inlining off in the packages no hot path calls, which saves
  about 830 KB on linux/amd64 with no measured cost. ([#2053](https://github.com/Gaurav-Gosain/tuios/pull/2053))
- The ghostty backend makes 2 cgo calls a write. The dock is drawn from parts of known
  width, and its workspace strip only when it changes. ([#2021](https://github.com/Gaurav-Gosain/tuios/pull/2021), [#1972](https://github.com/Gaurav-Gosain/tuios/pull/1972), [#2002](https://github.com/Gaurav-Gosain/tuios/pull/2002))
- The binary is about 350 KB smaller: Errorf and JSON go out of line, and cold sorts and
  the lexer dictionary shrink. ([#1513](https://github.com/Gaurav-Gosain/tuios/pull/1513), [#1514](https://github.com/Gaurav-Gosain/tuios/pull/1514))
- The emulator stores only the content of plain cells on a scroll, and builds a screen's
  tail text in one buffer. ([#1495](https://github.com/Gaurav-Gosain/tuios/pull/1495), [#1519](https://github.com/Gaurav-Gosain/tuios/pull/1519), [#1625](https://github.com/Gaurav-Gosain/tuios/pull/1625) by @Gsirawan)
- Quick look keeps its panel until its content changes, searches and draws its matches
  in one walk, and keeps pictures smaller. ([#1437](https://github.com/Gaurav-Gosain/tuios/pull/1437), [#1584](https://github.com/Gaurav-Gosain/tuios/pull/1584), [#1618](https://github.com/Gaurav-Gosain/tuios/pull/1618), [#1620](https://github.com/Gaurav-Gosain/tuios/pull/1620), [#1628](https://github.com/Gaurav-Gosain/tuios/pull/1628), by
  @Gsirawan)
- The daemon sends no listing push for a spinner frame, checks a prompt gate only on its
  own pane's events, and hashes the state fingerprint more cheaply. ([#1594](https://github.com/Gaurav-Gosain/tuios/pull/1594); [#1617](https://github.com/Gaurav-Gosain/tuios/pull/1617), [#1435](https://github.com/Gaurav-Gosain/tuios/pull/1435),
  by @Gsirawan)
- Each TML surface renders with its own hooks and no lock. ([#1685](https://github.com/Gaurav-Gosain/tuios/pull/1685))
- Worktree rows read in one status walk each, concurrently. ([#1485](https://github.com/Gaurav-Gosain/tuios/pull/1485), by @davidreuss)
