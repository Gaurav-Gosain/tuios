tuios 0.13.0 is a big one, so I skipped 0.12.2 and gave it a new minor number. Agents get a task board that runs itself, from a card to a pull request, and an agent can hand work to a child agent and get the answer back by mail. You can now move the daemon to a new build without ending a single pane, and the client on your machine follows it. Linking another machine is one command, `tuios hosts setup`. You can write your own actions and change the right-click menus in `config.toml`. Frames are written as cells now, so a typed key costs about a fifth of what it did. Quick look reads much more, plugins get a full toolkit, and bash and zsh panes get prompt marks with no change to your files. [What's new](https://tuios.dev/docs/whats-new) has the short version, with a link to each page.

## Upgrading from v0.12.1: one restart

A v0.12.1 daemon predates live upgrades, so it cannot hand its panes over. After you install, move it to the new build once:

```bash
tuios restart-server
```

The restart stops the programs in your panes. Each session comes back with its layout, the last 1000 lines of each pane's history and new shells. From v0.13.0 on, the next upgrade is live on macOS and Linux: `tuios daemon upgrade` moves the daemon to the new build and every program keeps running. On Windows, `tuios restart-server` stays the way to move. [Upgrading to v0.13.0](https://tuios.dev/docs/upgrading-to-v0-13-0) lists what to check.

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.13.0
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.13.0
```

A binary installed by the script or from an archive updates with `tuios update`.

### What changes for you

- **Cell frames are the default.** The client writes frames as cells on every terminal you run tuios in, except on Windows, and on SSH and web clients. If the screen looks wrong, set `appearance.cell_frames = "off"` or start tuios with `TUIOS_CELL_FRAME=0`, and please tell me your terminal's name and version. ([#2001](https://github.com/Gaurav-Gosain/tuios/pull/2001))
- **One name per action.** Actions that had two or more names, such as `prefix_new_window` and `window_prefix_new` for `new_window`, have one name now. The older names still work in your config, presets, tapes and over the protocol, and `tuios keybinds list` shows them as "(also: ...)". A keybinding that names an action tuios does not know now gets a warning when the config loads. The names an older tuios wrote into `config.toml` itself, such as `nav_up`, load quietly. ([#2014](https://github.com/Gaurav-Gosain/tuios/pull/2014), [#1982](https://github.com/Gaurav-Gosain/tuios/pull/1982), [#2085](https://github.com/Gaurav-Gosain/tuios/pull/2085))
- **Usage limits have their own state.** An agent that stops on a usage or rate limit is `limit_reached` now, not `errored`. A script that waits for `errored` on a limit should look for `limit_reached`. ([#2059](https://github.com/Gaurav-Gosain/tuios/pull/2059))
- **Go-to holds the switchers.** The session switcher, the workspace switcher and the window list are now go-to, and pane rows show their folder. Every list takes the keys of `[keybindings.lists]`. ([#1989](https://github.com/Gaurav-Gosain/tuios/pull/1989), [#2012](https://github.com/Gaurav-Gosain/tuios/pull/2012))
- **Popups sit in the middle of the screen**, clear of the rail, and the agents view no longer dims the dock and the rail. ([#1839](https://github.com/Gaurav-Gosain/tuios/pull/1839), [#1844](https://github.com/Gaurav-Gosain/tuios/pull/1844))
- **The dock orders minimized panes by window order**, so dock pill N and restore N pick the same pane on every client. ([#1852](https://github.com/Gaurav-Gosain/tuios/pull/1852))
- **Hooks talk to the daemon directly.** Run `tuios integration install` again to get hook commands that send each event to the daemon socket with `nc -U` or `socat`, so a hook no longer starts a whole tuios. Without either program, nothing changes. ([#1908](https://github.com/Gaurav-Gosain/tuios/pull/1908), [#1918](https://github.com/Gaurav-Gosain/tuios/pull/1918), [#1919](https://github.com/Gaurav-Gosain/tuios/pull/1919))
- **bash and zsh panes get OSC 133 prompt marks.** Set `[shell] integration = "off"` to start shells as before. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- **The rarer Mermaid diagram types moved to the `sketch` plugin.** Eight common types still draw in tuios. For the rest, run `tuios plugins install sketch`. ([#1467](https://github.com/Gaurav-Gosain/tuios/pull/1467), [#1505](https://github.com/Gaurav-Gosain/tuios/pull/1505))
- **Building from source** needs the Go 1.27.4 toolchain, which `go install` fetches for you. A plain `go install` binary is about 0.8 MB larger than the release, which turns inlining off in the cold packages. The ghostty backend now uses libghostty-vt 1.0.1: rebuild it with `scripts/install.sh ghostty`. ([#1876](https://github.com/Gaurav-Gosain/tuios/pull/1876), [#2053](https://github.com/Gaurav-Gosain/tuios/pull/2053), [#1775](https://github.com/Gaurav-Gosain/tuios/pull/1775), [#2009](https://github.com/Gaurav-Gosain/tuios/pull/2009))

## The terminal

- **Actions and menus of your own.** `[[actions]]` in `config.toml` declares an action: a built-in one, a program with the focused pane's folder or title as an argument, or a plugin action. Bind it to a key, find it in the command palette, run it with `tuios actions run`. `[menus.NAME]` is one table for every menu: the which-key panels and the right-click menus, where `add`, `after` and `remove` change the rows tuios ships. ([#2036](https://github.com/Gaurav-Gosain/tuios/pull/2036), [#2037](https://github.com/Gaurav-Gosain/tuios/pull/2037))

```toml
[[actions]]
name = "open-in-editor"
label = "Open the folder in the editor"
key = "prefix+alt+e"
run = ["code", "{pane.cwd}"]
in = "silent"
```

`tuios actions run open-in-editor --dry-run` prints what it would run, with the placeholders filled.

- **Faster frames.** The client writes each frame as cells and sends the terminal only what changed. With a typed key in a 200x60 window the frame went from 1023 us to 205 us, and from 792 to 376 allocations. ([#2001](https://github.com/Gaurav-Gosain/tuios/pull/2001), [#2050](https://github.com/Gaurav-Gosain/tuios/pull/2050))
- **Prompt marks in bash and zsh.** tuios turns on OSC 133 marks in the shells it starts, without editing your files, so the scrollback browser, `tuios run` and copy mode know where each command starts and ends. ([#1611](https://github.com/Gaurav-Gosain/tuios/pull/1611))
- **Drag and drop with the desktop.** Drags go to and from the desktop through kitty's drag and drop protocol. Thanks to @dschmidt. ([#1374](https://github.com/Gaurav-Gosain/tuios/pull/1374), [#1530](https://github.com/Gaurav-Gosain/tuios/pull/1530))
- A press during a pane resize cancels the resize, so a drag can no longer leave two tiled panes on top of each other. ([#2078](https://github.com/Gaurav-Gosain/tuios/pull/2078), [#2079](https://github.com/Gaurav-Gosain/tuios/pull/2079))

- [`tuios.dev/vt/dnd`](https://tuios.dev/vt/dnd) is the kitty drag and drop protocol codec, as a package of `tuios.dev/vt`. ([#2066](https://github.com/Gaurav-Gosain/tuios/pull/2066))
