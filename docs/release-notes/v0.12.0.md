New here? `tuios tutor` now teaches the basics in your own terminal.

tuios 0.12.0 makes the files in the rail useful: drag a file onto a pane to type its path, and press `space` to look inside it first. Agents get a task board, and you can bring back many agents at once after a restart. A settled agent stays out of your way until it needs you. Calm mode stops motion and quiets messages with one key. Return notes tell you what a session or a pane is for when you come back to it. The rail can run a live terminal of its own.

This release also fixes a denial of service in `tuios ssh`. If you run `tuios ssh` where other people can reach it, please update. Read [Security](#security) first.

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.12.0
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.12.0
```

A binary installed by the script or from an archive updates with `tuios update`. Then run `tuios restart-server` to move the daemon to the new build. The restart stops the programs in your panes. Each session comes back with its layout, its pane history and new shells.

## Before you upgrade

- **macOS 13 or later.** tuios is now built with Go 1.27.3, which needs macOS 13 (Ventura) or later. On macOS 12 or earlier, stay on v0.11.1 ([#1342](https://github.com/Gaurav-Gosain/tuios/pull/1342)).
- **Restart the daemon.** The SSH fix and most other fixes are in the daemon. An old daemon keeps the old behaviour until you run `tuios restart-server`. There is no live move from a v0.11.1 daemon, because the handoff format is now version 2 ([#1365](https://github.com/Gaurav-Gosain/tuios/pull/1365)).
- **Copy commands that print nothing.** A `copy_command` or copy pipe that exits 0 and prints nothing no longer fills the clipboard. A command such as `xclip -selection primary >/dev/null` now leaves the clipboard as it was. This matches tmux ([#1372](https://github.com/Gaurav-Gosain/tuios/pull/1372)).
- **Resume keeps your flags.** An agent now resumes with the flags you started it with, such as `--model`. A flag that turns approvals off gets a warning, and `daemon.resume_agents = "auto"` does not resume that agent. Press `y` to resume it ([#1359](https://github.com/Gaurav-Gosain/tuios/pull/1359)).
- **A quiet agent can show as `unknown`.** A hooked agent that reported `working` and then sends no report for 10 minutes now reads `state: unknown` and `reason: silent` in `list-agents` and `get-agent-state`. Set `[agents] silent_after = "off"` to turn this off ([#1353](https://github.com/Gaurav-Gosain/tuios/pull/1353)).
- **Settled replaces Earlier.** The Earlier group in the agents view is now the Settled shelf ([#1360](https://github.com/Gaurav-Gosain/tuios/pull/1360)).
- **Shorter info messages.** An info or success message now stays up for 2 seconds, not 6. Set `notifications.duration` to change this ([#1210](https://github.com/Gaurav-Gosain/tuios/pull/1210)).
- **The `ascii` glyph set.** `glyphs = "ascii"` now also draws the agent state marks in ASCII ([#1046](https://github.com/Gaurav-Gosain/tuios/pull/1046)).

## Security

### A client could stop `tuios ssh` from serving anyone

v0.12.0 fixes [GHSA-m75w-mvwc-578j](https://github.com/Gaurav-Gosain/tuios/security/advisories/GHSA-m75w-mvwc-578j). It affects v0.11.1 and earlier. A CVE is requested. Thanks to @Gsirawan for the report.

- `tuios ssh` had no time limit on the SSH login and no limit on connections or sessions. A client that did not finish its login kept its connection open for as long as it liked.
- Many such connections could use up the server's resources. In daemon mode this could also stop the daemon from opening panes.
- Now `tuios ssh` closes a login that takes longer than 120 seconds. It also limits the logins in progress to 32 and the open sessions to 64. A new `[ssh]` section in the config file and four new flags on `tuios ssh` set these limits, and an optional idle timeout ([#1298](https://github.com/Gaurav-Gosain/tuios/pull/1298)).

What you notice: nothing, in normal use. If you run `tuios ssh` where other people can reach it, update and restart it. When the session limit is reached, a new client gets a message that says so. [Docs](https://tuios.dev/docs/configuration#ssh-server-limits)

### Other hardening

- A file that a linked machine or a paired phone writes here gets your umask, and never group or world write ([#1295](https://github.com/Gaurav-Gosain/tuios/pull/1295)). Thanks to @Gsirawan for the report.
- A new setting, `files_max_entries`, limits how many new files and folders one linked machine makes here in ten minutes. The default is 20,000 ([#1296](https://github.com/Gaurav-Gosain/tuios/pull/1296)). Thanks to @Gsirawan for the report.
- A linked machine with `files` can no longer read the credentials of more common tools, or write the config folders of the agent tools that tuios supports ([#1288](https://github.com/Gaurav-Gosain/tuios/pull/1288)). Thanks to @Gsirawan.
- tuios-web warns when your password is shorter than 12 characters ([#1185](https://github.com/Gaurav-Gosain/tuios/pull/1185)). Thanks to @Gsirawan.
- The mailbox between agents keeps its send limits bounded ([#1277](https://github.com/Gaurav-Gosain/tuios/pull/1277)). Thanks to @Gsirawan.

## Highlights

- **`tuios tutor`.** Learn the basics in your own terminal, in nine steps. The shell and the files are a practice copy, so nothing on your computer changes. The tutor starts no daemon ([#1339](https://github.com/Gaurav-Gosain/tuios/pull/1339)).
- **The Settled shelf.** In the agents view, `D` puts an agent on the Settled shelf. It keeps running, and it comes back by itself when it asks you something, errors or finishes a turn. Every client shows the same shelf ([#1360](https://github.com/Gaurav-Gosain/tuios/pull/1360)).
- **Stage from the review.** In the review overlay, `a` and `d` stage and unstage the hunk under the cursor. `A` and `D` do this for the whole file, and `z` undoes the last one ([#1356](https://github.com/Gaurav-Gosain/tuios/pull/1356)).
- **Drag a file into a pane.** Drag a row from the files section of the rail onto a pane. tuios types the path at the cursor, quoted for that pane's shell ([#1335](https://github.com/Gaurav-Gosain/tuios/pull/1335)).
- **Quick look.** Put the rail cursor on a file and press `space`. You see the code with colours and line numbers, Markdown laid out, a picture, the first page of a PDF, a frame of a film, or the names in a folder. A PDF page needs `pdftoppm` and a film frame needs `ffmpeg` on the machine that has the file ([#1337](https://github.com/Gaurav-Gosain/tuios/pull/1337)). Right-click a file and pick Preview to look at that row ([#1369](https://github.com/Gaurav-Gosain/tuios/pull/1369)).
- **Drag and drop between panes.** Set `[panes] drag_and_drop = true`. A program that speaks kitty's protocol, such as yazi 26.9 or later, can then drag files to another pane. The switch is off by default because the protocol is still settling. Thanks to @dschmidt ([#1307](https://github.com/Gaurav-Gosain/tuios/pull/1307)).
- **A path picker at the cursor.** `Alt+;` in terminal mode, or `Ctrl+B .`, opens a small list of the files in the pane's folder. Type to filter, and `enter` puts the path at the prompt ([#1235](https://github.com/Gaurav-Gosain/tuios/pull/1235)).
- **Task cards and the task board.** A session can hold task cards. Agents claim, finish, block and release them with `tuios task`. In the agents view, `b` groups the task cards by stage, `t` takes a card and `n` starts a new agent on it. A card now moves on its own when its plan, its fan check or its pull request changes, and `fan` and `start-agent` take a `task`. Set `[tasks] auto_stage = false` to stop the moves. Thanks to @shubham-tomar ([#1158](https://github.com/Gaurav-Gosain/tuios/pull/1158), [#1248](https://github.com/Gaurav-Gosain/tuios/pull/1248), [#1332](https://github.com/Gaurav-Gosain/tuios/pull/1332)).
- **Resume many agents at once.** After a restart, mark Resume rows in the agents view with `x` or `*`, and press `y` to resume all of them. The view stays open ([#1334](https://github.com/Gaurav-Gosain/tuios/pull/1334)).
- **Calm mode.** `Ctrl+B Z` stops all motion and quiets the dock. Set `appearance.calm = true` to keep it on ([#1209](https://github.com/Gaurav-Gosain/tuios/pull/1209)).
- **Return notes.** `tuios note set TEXT` puts one short line on a session or a pane, such as what comes next. The note stays after a detach and a daemon restart ([#1218](https://github.com/Gaurav-Gosain/tuios/pull/1218)).
- **A live terminal in the rail.** A new `pane` section in the rail runs a program in a real terminal under its own heading ([#1221](https://github.com/Gaurav-Gosain/tuios/pull/1221)).
- **Nest mode.** The `nest` action sends every key to the focused pane, the leader too, until you press `F12`. Use it for a tmux or a tuios inside a pane. Thanks to @udiNur ([#1190](https://github.com/Gaurav-Gosain/tuios/pull/1190)).
- **One session order everywhere.** The daemon keeps the order of your sessions. Move a session on one rail and it moves on every client, in `tuios ls`, and after a restart. Thanks to @udiNur ([#1191](https://github.com/Gaurav-Gosain/tuios/pull/1191)).
- **Share your look.** `tuios look export` writes your setup as a look file that `tuios look apply` reads. Share it in [Show us your tuios setup](https://github.com/Gaurav-Gosain/tuios/discussions/849) ([#1261](https://github.com/Gaurav-Gosain/tuios/pull/1261)).
- **Termux.** A new Android arm64 build runs tuios on Termux ([#1230](https://github.com/Gaurav-Gosain/tuios/pull/1230)).

## Performance

- A long run of work by @Gsirawan makes tuios lighter: less work for ASCII text in the emulator, the search line and loom, smaller buffers after a flood of output, and memory given back when a session ends or its history is dropped ([#1167](https://github.com/Gaurav-Gosain/tuios/pull/1167), [#1168](https://github.com/Gaurav-Gosain/tuios/pull/1168), [#1171](https://github.com/Gaurav-Gosain/tuios/pull/1171), [#1174](https://github.com/Gaurav-Gosain/tuios/pull/1174), [#1180](https://github.com/Gaurav-Gosain/tuios/pull/1180), [#1181](https://github.com/Gaurav-Gosain/tuios/pull/1181), [#1196](https://github.com/Gaurav-Gosain/tuios/pull/1196), [#1198](https://github.com/Gaurav-Gosain/tuios/pull/1198), [#1206](https://github.com/Gaurav-Gosain/tuios/pull/1206), [#1214](https://github.com/Gaurav-Gosain/tuios/pull/1214), [#1216](https://github.com/Gaurav-Gosain/tuios/pull/1216), [#1266](https://github.com/Gaurav-Gosain/tuios/pull/1266), [#1274](https://github.com/Gaurav-Gosain/tuios/pull/1274), [#1282](https://github.com/Gaurav-Gosain/tuios/pull/1282), [#1290](https://github.com/Gaurav-Gosain/tuios/pull/1290)).
- Size work pays for most of the new features. Go 1.27.3 saves about 640 KB, and code changes save about 800 KB and 115 KB more ([#1342](https://github.com/Gaurav-Gosain/tuios/pull/1342), [#1376](https://github.com/Gaurav-Gosain/tuios/pull/1376), [#1336](https://github.com/Gaurav-Gosain/tuios/pull/1336)). @Gsirawan cut about 312 KiB from the Mermaid code on linux/amd64 ([#1276](https://github.com/Gaurav-Gosain/tuios/pull/1276)), and more from cold sorts ([#1186](https://github.com/Gaurav-Gosain/tuios/pull/1186), [#1178](https://github.com/Gaurav-Gosain/tuios/pull/1178)). The linux/amd64 binary is 48.8 MB, against 47.9 MB in v0.11.1.
