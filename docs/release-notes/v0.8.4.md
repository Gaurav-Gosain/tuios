tuios 0.8.4 is a fix release. It repairs the default mode of `tuios xpanes` and removes more invisible characters from untrusted text. It also fixes the Homebrew cask warning and a race in the herdr socket.

The full list is at [tuios.dev/releases](https://tuios.dev/releases).

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.8.4
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.8.4
```

A binary installed by the script or from an archive updates with `tuios update`.

## Fixes

- **xpanes.** In v0.8.3, `tuios xpanes` with no `-s` typed every command into the first pane, and no command ran ([#310](https://github.com/Gaurav-Gosain/tuios/pull/310)).
  - Each command now goes to its own pane.
  - tuios waits for the shell prompt of the pane before it types the command.
  - With `-ss`, a pane closes when its command ends, also when no client is attached.
- **Untrusted text.** The untrusted content fence removes every invisible character ([#314](https://github.com/Gaurav-Gosain/tuios/pull/314)).
  - This adds the line and paragraph separators, the soft hyphen, the tag characters, the variation selectors and the other format characters.
  - A line or paragraph separator becomes a line break.
  - A zero-width joiner stays only between two emoji.
  - Mail, replies, captures from a host, notifications, agent titles and approval lines use the same rule.
- **herdr socket.** A caller over the connection limit gets a `rate_limited` answer. Before, its write sometimes failed with a broken pipe ([#315](https://github.com/Gaurav-Gosain/tuios/pull/315)).
- **Pane capture.** Two waits on one pane no longer race when they read its screen ([#315](https://github.com/Gaurav-Gosain/tuios/pull/315)).
- **Homebrew.** The casks use `postflight_steps`. Homebrew no longer shows a deprecation warning on install or upgrade ([#311](https://github.com/Gaurav-Gosain/tuios/pull/311)).

## Upgrade

The fixes to `-ss`, the fence and the herdr socket are in the daemon. To start a v0.8.4 daemon, run `tuios kill-server` after the upgrade. This closes every pane in every session, so save your work first.
