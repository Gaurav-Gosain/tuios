tuios 0.13.2 is a small release, and nearly all of it is the agents view (`ctrl+b i`). This round fixes the rough edges that show up when you run a lot of agents at once. Code blocks in the thread wrap, scroll sideways and copy with one key. File paths open in quick look on a click. An answer moves you to the next agent that needs you, and `r` no longer rejects anything.

Upgrading from v0.13.1 is live on macOS and Linux: install, then run `tuios daemon upgrade`, and every program in your panes keeps running.

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.13.2
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.13.2
```

A binary installed by the script or from an archive updates with `tuios update`.

## Agents view

- **`r` always replies, and `X` rejects.** Before, `r` rejected a held approval, so a reply could turn into a reject. On a held approval or plan, `r` now tells you to press `a` or `X` first. A user who bound `X` in the agents view keeps that binding. ([#2131](https://github.com/Gaurav-Gosain/tuios/pull/2131))
- **Code blocks in the thread.** A cut line ends with a quiet `…`. `W` wraps the long lines of every block, and `W` again cuts them. `(` and `)` or a sideways wheel scroll a wide block. `copy` in a block's header, or `C`, copies the whole block as the agent wrote it. ([#2102](https://github.com/Gaurav-Gosain/tuios/pull/2102), [#2106](https://github.com/Gaurav-Gosain/tuios/pull/2106), [#2108](https://github.com/Gaurav-Gosain/tuios/pull/2108))
- **Links and paths open on a click.** A click on a link in the view opens it, and `gx` does the same in copy mode. A file path that exists opens in quick look at the line it names: a plain click in the view, `ctrl+click` in a pane. `e` in quick look opens the file in your editor at that line. A `file://` link now opens in quick look first. ([#2113](https://github.com/Gaurav-Gosain/tuios/pull/2113), [#2117](https://github.com/Gaurav-Gosain/tuios/pull/2117))
- **Select the thread with the mouse.** Drag across cards, double click a word, triple click a line. A right click on the selection offers Copy, Copy as Markdown and Search for it. In copy mode a click moves the cursor. ([#2122](https://github.com/Gaurav-Gosain/tuios/pull/2122))
- **An answer moves to the next agent that needs you,** so a queue of approvals is `a` `enter`, `a` `enter`. Set `[agents] answer_advance = false` to stay on the agent you answered. ([#2107](https://github.com/Gaurav-Gosain/tuios/pull/2107))
- **Questions show their options as keys.** A question from Claude Code reads "Asks" with its text, and a digit picks an option. ([#2112](https://github.com/Gaurav-Gosain/tuios/pull/2112))
- **Mail between agents draws as message cards,** with the subject, the message, whether it was read and the replies under it. A Talked with line under the focus header has a chip for each agent this one wrote to, and a click selects that agent. ([#2100](https://github.com/Gaurav-Gosain/tuios/pull/2100), [#2103](https://github.com/Gaurav-Gosain/tuios/pull/2103))
- **A long plan reads by page.** `J` and `K` move a page, `G` goes to the end, and `Z` gives the card the whole focus. The plan draws as Markdown. ([#2104](https://github.com/Gaurav-Gosain/tuios/pull/2104))
- **Compare uses `J` to ask a judge and `K` to keep,** so `j` and `k` move, as everywhere else. ([#2116](https://github.com/Gaurav-Gosain/tuios/pull/2116))
- **Agents that share a folder are marked "shared folder",** and the New agent sheet suggests a worktree when agents already work there. ([#2123](https://github.com/Gaurav-Gosain/tuios/pull/2123))
- A new agent takes its name from its branch or its task, not from the title its program sets. ([#2110](https://github.com/Gaurav-Gosain/tuios/pull/2110))
- Paths show relative to the agent's worktree: `cmd/main.go`, not the last three parts of an absolute path. ([#2111](https://github.com/Gaurav-Gosain/tuios/pull/2111))
- The Changes tab gives its rows to the diff and opens at the first file. ([#2127](https://github.com/Gaurav-Gosain/tuios/pull/2127))
- Search finds names first and keeps the cursor on the agent you found. The search box keeps its place at every width. ([#2118](https://github.com/Gaurav-Gosain/tuios/pull/2118))
- A narrowed view says "1 of 8 agents · esc shows all", and `esc` brings every agent back. ([#2109](https://github.com/Gaurav-Gosain/tuios/pull/2109))
- At 80 columns, or in a long group, a one-line row still says what the agent needs or does. ([#2115](https://github.com/Gaurav-Gosain/tuios/pull/2115))
- On a light terminal with no theme set, the agents view is light too. ([#2119](https://github.com/Gaurav-Gosain/tuios/pull/2119))
- A followed thread streams in place. A sent prompt no longer jumps to the top, and the live row becomes the call's card without a jump. ([#2099](https://github.com/Gaurav-Gosain/tuios/pull/2099))

## Fixes

- The reply editor no longer crashes when `ctrl+r`, the external editor or a drag changes the draft while the `@` list is open. Thanks to @Gsirawan. ([#2130](https://github.com/Gaurav-Gosain/tuios/pull/2130))
- A thread that opened before its agent had a transcript now reads the transcript when it comes, with no key pressed. ([#2101](https://github.com/Gaurav-Gosain/tuios/pull/2101))
- An answer key that does nothing says why on the card. `enter` on a held approval in another session hands the prompt back to its pane. ([#2105](https://github.com/Gaurav-Gosain/tuios/pull/2105))
- A reply to an agent on another machine is queued there when you are attached through a host. ([#2129](https://github.com/Gaurav-Gosain/tuios/pull/2129))
- Bold around a code span closes when more code follows on the line, so ``**`main.go`:**`` no longer shows its stars. ([#2120](https://github.com/Gaurav-Gosain/tuios/pull/2120))
- The rename field selects with shift and the arrows, and a selection looks the same in both directions. ([#2121](https://github.com/Gaurav-Gosain/tuios/pull/2121))
- `tuios integration status` says what differs when the installed hooks have the same version but are not the ones this build writes. ([#2098](https://github.com/Gaurav-Gosain/tuios/pull/2098))
- A stopped git no longer leaves an index lock file in the temp folder. ([#2128](https://github.com/Gaurav-Gosain/tuios/pull/2128))
