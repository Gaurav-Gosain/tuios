tuios 0.12.1 fixes a crash on the task board and makes right-click Preview work from any pane. The rail now shows the names your agents set. The drop preview is now only a frame by default.

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.12.1
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.12.1
```

A binary installed by the script or from an archive updates with `tuios update`. Then run `tuios restart-server` to move the daemon to the new build. The restart stops the programs in your panes. Each session comes back with its layout, its pane history and new shells.

## Before you upgrade

- **The drop preview is only a frame.** While you drag a pane in BSP, the preview now draws a frame with no tint inside. Set `appearance.drop_preview = "fill"` to get the tint back ([#1408](https://github.com/Gaurav-Gosain/tuios/pull/1408)).
- **A correction to the v0.12.0 notes.** `tuios restart-server` does not apply the SSH fix from v0.12.0, because the limits are in the `tuios ssh` process. If you run `tuios ssh` where other people can reach it, restart that process too ([#1392](https://github.com/Gaurav-Gosain/tuios/pull/1392)).

## Fixes

- The task board no longer crashes when the selection reaches the folded Done heading ([#1409](https://github.com/Gaurav-Gosain/tuios/pull/1409)).
- Right-click a file and pick Preview now works from any focus. In v0.12.0 the preview closed at once unless the rail had the keyboard and its cursor was on a file ([#1387](https://github.com/Gaurav-Gosain/tuios/pull/1387)).
- `next_session`, `prev_session` and `switch_session_N` now follow the order of the rail's rows, and the number beside a row is the key that opens it. Thanks to @zerone0x, and to @maciej-lech for the report ([#1300](https://github.com/Gaurav-Gosain/tuios/pull/1300)).
- The sessions section scrolls to a new or switched-to session when the list is grouped. Thanks to @maciej-lech for the report ([#1401](https://github.com/Gaurav-Gosain/tuios/pull/1401)).
- The `files` control in the rail's footer now opens the files section when `appearance.sidebar.sections` leaves it out. You can keep the section hidden by default and open it when you need it. Thanks to @maciej-lech for the report ([#1407](https://github.com/Gaurav-Gosain/tuios/pull/1407)).
- Two data races are gone: one on a pane's folder report and one on `OS.SetTheme` ([#1402](https://github.com/Gaurav-Gosain/tuios/pull/1402), [#1403](https://github.com/Gaurav-Gosain/tuios/pull/1403)).

## New

- **Agent names in the rail.** A row now shows the title that an agent set, such as the name from `claude -n` or `/rename`. A custom name still comes first. When several agents show only the program, each row has a suffix that stays with its pane. Thanks to @zoneblaze for the report and the first proposal ([#1388](https://github.com/Gaurav-Gosain/tuios/pull/1388)).
- **Open a review on the file list.** Set `[review] focus = "files"`. Thanks to @maciej-lech ([#1378](https://github.com/Gaurav-Gosain/tuios/pull/1378)).
- **More surfaces follow your look.** With `appearance.pane_overlays` on, the plugin approval dialog, the scrollback browser and the copy-mode search bar take the pane look. The scrollback browser and its help modal also follow `appearance.border_style`. Thanks to @abhijit-s ([#1096](https://github.com/Gaurav-Gosain/tuios/pull/1096), [#1108](https://github.com/Gaurav-Gosain/tuios/pull/1108)).
- **Windows.** A pane opens on the `conpty.dll` and `OpenConsole.exe` beside `tuios.exe` when both files are there. With them, a pane's sixel images reach tuios. Without them, nothing changes. Thanks to @badmagick329 ([#1389](https://github.com/Gaurav-Gosain/tuios/pull/1389)).
- **For the apps.** The new `list-routes` verb gives the addresses a phone can reach this machine on, and `queue-prompt` takes a `client_id`, so a resend queues once ([#1380](https://github.com/Gaurav-Gosain/tuios/pull/1380), [#1379](https://github.com/Gaurav-Gosain/tuios/pull/1379)). The GUI bridge reports the queue, the draft and the shelf, and it can read an agent's transcript ([#1377](https://github.com/Gaurav-Gosain/tuios/pull/1377)).
