tuios 0.9.0 is a big one: about 490 commits since v0.8.5. Any program can now tell tuios what it is doing, your config can live in more than one file, and yanks stay around as paste buffers. You can take a session for yourself with `attach -d`, your ssh agent follows you into your panes, and images show up even on a terminal with no graphics at all.

https://github.com/user-attachments/assets/e2cfe043-ea9c-4e84-9950-46114ae093bb


Before you upgrade, read [Upgrading](#upgrading). The daemon protocol gained new messages, so restart the daemon after you install.

The full list is at [tuios.dev/releases](https://tuios.dev/releases).

## Install

```bash
brew install tuios                     # Homebrew (macOS, Linux)
yay -S tuios-bin                       # AUR (tuios-web-bin for the web server)
nix run github:Gaurav-Gosain/tuios     # Nix
curl -fsSL https://raw.githubusercontent.com/Gaurav-Gosain/tuios/main/install.sh | bash
go install github.com/Gaurav-Gosain/tuios/cmd/tuios@v0.9.0
docker run -it --rm ghcr.io/gaurav-gosain/tuios:v0.9.0
```

- A binary installed by the script or from an archive updates with `tuios update`.
- **The ghostty build on Homebrew.** `brew install gaurav-gosain/tap/tuios-ghostty` installs `tuios` built with libghostty-vt, on Linux. It installs a binary with the same name as the `tuios` formula, so run `brew uninstall tuios` first. On macOS, take the `tuios-ghostty_*_Darwin_*` archive from this page.
- **The `tuios` cask is deprecated.** `brew install tuios` gives you the homebrew-core formula. If you installed the cask from my tap, move to the formula with `brew uninstall --cask tuios && brew install tuios`.

## Highlights

- **Program status (OSC 7501).** Any program in a pane can report that it is working, blocked, done or failed, with the Program Status Protocol. A build, a deploy script or `brew` then shows on the rail and in the Inbox like an agent, with no hook or plugin ([#546](https://github.com/Gaurav-Gosain/tuios/pull/546)). Docs: [Program Status](https://tuios.dev/docs/program-status).
- **Split the config.** `include = [...]` in config.toml and a `config.d` folder let you keep machine-only settings, such as hosts, out of your shared dotfiles. A read-only file from Nix or home-manager stays read-only, and the settings page writes its changes to a file it may change ([#547](https://github.com/Gaurav-Gosain/tuios/pull/547), asked for in [#518](https://github.com/Gaurav-Gosain/tuios/issues/518)). Docs: [Split the Config](https://tuios.dev/docs/config-files).
- **Paste buffers.** Each yank is kept as a paste buffer, as in tmux. `Ctrl+B ]` pastes the newest one and `Ctrl+B #` lists them all. `list-buffers`, `set-buffer`, `paste-buffer` and the tmux shim use the same buffers ([#550](https://github.com/Gaurav-Gosain/tuios/pull/550), asked for in [#514](https://github.com/Gaurav-Gosain/tuios/issues/514)). Docs: [Paste buffers](https://tuios.dev/docs/paste-buffers).
- **One client per session.** `tuios attach -d NAME` detaches every other client as you attach, as `tmux attach -d` does. `tuios detach-client` detaches clients without an attach, and `[daemon] single_client = true` makes every attach work like `-d` ([#551](https://github.com/Gaurav-Gosain/tuios/pull/551)). Docs: [Detaching other clients](https://tuios.dev/docs/sessions#detaching-other-clients).
- **Your ssh agent follows you.** With `[daemon] ssh_agent = "follow"`, new panes use the ssh agent of the client you attached from, and they move with you when you attach from another machine. This also works through a remote host, when your ssh link forwards the agent ([#552](https://github.com/Gaurav-Gosain/tuios/pull/552)). Docs: [SSH Agent](https://tuios.dev/docs/ssh-agent).
- **Images without graphics.** On a terminal with no sixel or kitty graphics, such as kmscon, the Linux console or a plain SSH client, tuios now draws pane images with block glyphs. kmscon gets octants, the Linux console gets half blocks, and everything else gets quadrants ([#548](https://github.com/Gaurav-Gosain/tuios/pull/548)). Docs: [Images Without Graphics](https://tuios.dev/docs/images-without-graphics).
- **Agents and the Inbox.**
  - Crush permission prompts wait in the Inbox like the others ([#320](https://github.com/Gaurav-Gosain/tuios/pull/320)). Docs: [herdr Compatibility](https://tuios.dev/docs/herdr-compatibility#crush-permission-prompts).
  - `tuios checkpoint` saves an agent's work tree at the end of each turn, and puts it back when you ask. Docs: [Checkpoints](https://tuios.dev/docs/checkpoints).
  - `tuios ship` commits, merges, pushes and opens the pull request for a worktree. The rail shows the pull request and its checks. Docs: [Ship](https://tuios.dev/docs/ship).
  - The Inbox can send push notifications through ntfy, Pushover or a webhook. Try it with `tuios notify test`. Docs: [Push Notifications](https://tuios.dev/docs/push-notifications).
  - `[agents] enabled = false` turns off every agent feature, if you want a plain multiplexer ([#387](https://github.com/Gaurav-Gosain/tuios/pull/387)). Docs: [Turn Off Agent Features](https://tuios.dev/docs/agents-off).
  - The settings page has an Agents tab that installs and updates the harness integrations ([#474](https://github.com/Gaurav-Gosain/tuios/pull/474)).
- **The rail.** The sidebar is now shared by every client of a session, and the panes retile when you hide it ([#350](https://github.com/Gaurav-Gosain/tuios/pull/350)). You can add your own section fed by a command ([#419](https://github.com/Gaurav-Gosain/tuios/pull/419)), copy a folder's path, and turn on session numbers with `appearance.sidebar.show_numbers` ([#544](https://github.com/Gaurav-Gosain/tuios/pull/544)). Docs: [Session Rail](https://tuios.dev/docs/session-rail).
- **Find a pane.** `Ctrl+B /` opens a navigator over every pane in every session, on this machine and on your hosts. Search names, folders, commands and the text on screen, with a live preview in the pane's own colours ([#473](https://github.com/Gaurav-Gosain/tuios/pull/473), [#505](https://github.com/Gaurav-Gosain/tuios/pull/505)). `Ctrl+B Q` labels the panes so that you can jump to one with a key ([#472](https://github.com/Gaurav-Gosain/tuios/pull/472)). Docs: [Finding a pane](https://tuios.dev/docs/find-a-pane).
- **herdr.** tuios now hosts herdr plugins: their actions go in the palette and their panes open in tuios ([#435](https://github.com/Gaurav-Gosain/tuios/pull/435)). The herdr socket also answers the pane, agent and client methods that plugins still missed ([#433](https://github.com/Gaurav-Gosain/tuios/pull/433)). Docs: [herdr Compatibility](https://tuios.dev/docs/herdr-compatibility).
- **tmux shim.** The shim accepts command prefixes, reads the tmux 3.4 format language, and adds `wait-for`, `display-popup`, `run-shell`, `if-shell`, pane and window moves, buffers, the environment and `detach-client`. About 90 format cases are checked against a real tmux. Docs: [tmux Shim](https://tuios.dev/docs/tmux-shim).
- **Speed.** Panes draw on one frame clock, so an animation at 120 Hz shows at 120 Hz. `max_fps` now goes up to 240, or `"auto"` to follow your display ([#407](https://github.com/Gaurav-Gosain/tuios/pull/407), [#520](https://github.com/Gaurav-Gosain/tuios/pull/520)). Copy-mode search went from 150 ms to 11 ms a key, an idle client uses less than half the CPU it did, and the daemon gives memory back after you close a lot of panes. Docs: [max_fps](https://tuios.dev/docs/configuration#max_fps).

## More new things

### Panes, layouts and workspaces

- **Neovim navigation.** The same keys move between nvim splits and tuios panes, with `appearance.nvim_navigation` ([#318](https://github.com/Gaurav-Gosain/tuios/pull/318)). Thanks to @Tim4c.
- **Borderless zoom.** `appearance.zoom_borderless` makes a zoomed pane fill the whole pane area with no border ([#531](https://github.com/Gaurav-Gosain/tuios/pull/531)).
- **Splits over ssh.** `split_ssh_horizontal`, `split_ssh_vertical` and `new_window_ssh` open the new pane on the machine the pane is ssh'd into. `appearance.new_window_follow_ssh` makes the normal split keys do it ([#471](https://github.com/Gaurav-Gosain/tuios/pull/471)).
- **Last pane.** `last_pane` (`;` in window mode) flips between the last two panes ([#469](https://github.com/Gaurav-Gosain/tuios/pull/469)). Thanks to @davidreuss.
- **Session keys.** `switch_session_1` to `switch_session_9`, and `rename_workspace` ([#464](https://github.com/Gaurav-Gosain/tuios/pull/464)). Thanks to @davidreuss.
- **Empty workspaces.** When the last pane on the workspace closes, tuios goes back to the workspace you showed before ([#427](https://github.com/Gaurav-Gosain/tuios/pull/427)). `[workspaces] new_window_when_empty = true` opens a pane when you switch to an empty workspace ([#485](https://github.com/Gaurav-Gosain/tuios/pull/485)).
- **Scrolling layout.** A column can fill the whole screen ([#402](https://github.com/Gaurav-Gosain/tuios/pull/402)). Thanks to @alnav3.

### Dock

- **Compact dock.** `appearance.dock_compact` draws the dock as one row ([#461](https://github.com/Gaurav-Gosain/tuios/pull/461)).
- **Rounded pills.** The dock pills are rounded by default ([#458](https://github.com/Gaurav-Gosain/tuios/pull/458)).
- **Mode icons.** `dock_mode_icon_window`, `dock_mode_icon_terminal` and `dock_mode_icon_tiling` set the mode pill icons ([#529](https://github.com/Gaurav-Gosain/tuios/pull/529)).
- **Labels.** `appearance.dock_workspace_label_max` caps a workspace label, and a minimized pane keeps its name while there is room ([#499](https://github.com/Gaurav-Gosain/tuios/pull/499)). Thanks to @davidreuss.
- **Mode keys.** The keys of the current mode show as a legend in the dock.

### Sessions, hosts and the CLI

- **Sessions from the CLI.** `tuios new --cwd DIR` starts a session in a folder, and `tuios switch-session [HOST:]NAME` moves your client to another session ([#457](https://github.com/Gaurav-Gosain/tuios/pull/457)).
- **Clients.** `tuios list-clients` lists the clients of the daemon, and a `client-session-changed` event says when one switches ([#410](https://github.com/Gaurav-Gosain/tuios/pull/410)). Thanks to @zer0ken.
- **Hosts.** `tuios hosts sync` installs this version on every host ([#431](https://github.com/Gaurav-Gosain/tuios/pull/431)). `--start` starts the daemon on a host ([#450](https://github.com/Gaurav-Gosain/tuios/pull/450)). A Tailscale SSH check now says "sign in" and opens the page ([#465](https://github.com/Gaurav-Gosain/tuios/pull/465), [#513](https://github.com/Gaurav-Gosain/tuios/pull/513)).
- **Explorers.** `tuios help -i`, `tuios config browse` and `tuios keybinds browse` let you search the commands, the options and the keys ([#436](https://github.com/Gaurav-Gosain/tuios/pull/436)).
- **Keys reload.** A key you save in config.toml works at the next key press, with no restart ([#454](https://github.com/Gaurav-Gosain/tuios/pull/454)). Thanks to @davidreuss.
- **Scripts.** More list commands take `--json`, the help is accurate, and errors say what to do ([#430](https://github.com/Gaurav-Gosain/tuios/pull/430)). `tuios close-window` is new ([#438](https://github.com/Gaurav-Gosain/tuios/pull/438)).
- **Tapes.** A tape can run any action and wait on conditions, and `tape exec` plays a tape to the end and reports the first failure ([#437](https://github.com/Gaurav-Gosain/tuios/pull/437)).
- **Launcher.** `launcher.gui_command` starts graphical desktop entries ([#346](https://github.com/Gaurav-Gosain/tuios/pull/346)).
- **MCP.** The MCP server speaks protocol versions 2025-11-25 and 2026-07-28.

### Copy mode and links

- **Links.** Ctrl+click opens a link, and OSC 8 links reach your outer terminal. Docs: [Links](https://tuios.dev/docs/links).
- **Home and End** go to the start and end of the line in copy mode ([#528](https://github.com/Gaurav-Gosain/tuios/pull/528)).

### Terminal emulation

- tuios answers XTVERSION, DA3, XTGETTCAP and DECRQSS, and supports xterm's modifyOtherKeys, the 1005 and 1015 mouse encodings and the title stack.
- Each pane gets its own key encoding, with releases, repeats and lock state as kitty sends them ([#377](https://github.com/Gaurav-Gosain/tuios/pull/377)).
- A pane that turns on focus reporting is told when it has focus ([#337](https://github.com/Gaurav-Gosain/tuios/pull/337)).
- A graphics pane is paced to its fastest client ([#345](https://github.com/Gaurav-Gosain/tuios/pull/345)).

## Security and robustness

- **Typing over a host link.** A pane on one machine can no longer answer a prompt on another machine unless that machine's link policy allows `respond` ([#389](https://github.com/Gaurav-Gosain/tuios/pull/389)).
- **Daemon memory.** The daemon checks a frame's size before it reads the frame, and all frames and requests share one read budget. A process that can reach the socket can no longer make the daemon hold a gigabyte ([#557](https://github.com/Gaurav-Gosain/tuios/pull/557), [#498](https://github.com/Gaurav-Gosain/tuios/pull/498)).
- **Paste buffers** have an owner. A pane without `admin` sees only its own buffers, never yours.
- **herdr plugins** wait for you before they run, and only a pane with `admin` reads the plugin log.
- **Dock components.** Their output is bounded, and unsafe characters are removed ([#404](https://github.com/Gaurav-Gosain/tuios/pull/404)).
- **ssh.** A followed ssh agent socket must pass the same folder checks as OpenSSH. A split that follows ssh keeps only known connection options.
- **ship and checkpoints.** `ship` pushes the commit you allowed, not the branch tip. A restore that would overwrite ignored files is refused. Notifications refuse a redirect to another host.
- **MCP.** Tools that change state are no longer marked read-only.
- **Events.** `tuios subscribe` refuses an event type it does not know, instead of printing nothing ([#438](https://github.com/Gaurav-Gosain/tuios/pull/438)).
- **No curl.** Notifications and `tuios update` use Go's own HTTP client. tuios no longer needs curl at run time.
- **Fuzzing.** Every fuzz target now runs in the nightly job ([#503](https://github.com/Gaurav-Gosain/tuios/pull/503)).

## Upgrading

### Restart the daemon

The protocol gained new messages for detach, session use, the shared sidebar, image glyphs, the ssh agent and request ids. Restart the daemon after you upgrade:

```bash
tuios kill-server
```

This closes every pane in every session, so save your work first. For your remote hosts, `tuios hosts sync --restart` installs this version and restarts each daemon. An older daemon ignores `attach -d`, and `tuios attach -d` warns you when that happens.

### Config

- **`opt+` is `alt+` everywhere.** A key such as `opt+1` now reads as `alt+1` on Linux too, so one config.toml works on a Mac and on Linux. On macOS, `opt+` keys work as before.
- **One bad key drops only that key.** tuios keeps the rest of the file and shows "N config problems, see the log viewer". Before, one bad key put every setting back to its default.
- **config.toml is sparse.** tuios now writes only the keys you changed, so that included files can apply. An older config.toml that lists every key holds every default too, and those keys win over your included files. To clean it, run:

  ```bash
  tuios config prune --dry-run   # see what it removes
  tuios config prune
  ```

  It keeps your comments and `[startup]`, and asks before it removes a key that another file sets.

### Images

- **chafa, timg and yazi now send sixel on hosts without graphics.** tuios tells panes that they can draw sixel and draws the image as glyphs. These tools then send sixel instead of their own text art. To go back to the box, set `appearance.image_symbols = "off"`.

### Changed defaults

- **Agent checkpoints are on.** At the end of each turn that changes a file, tuios saves the agent's work tree under `refs/tuios/checkpoints/` in that repository. To turn it off, set `[agents.checkpoints] enabled = false`.
- **The dock pills are rounded.** Set `appearance.dock_pill_caps = false` for the flat dock.
- **An empty workspace goes back.** When its last pane closes, tuios shows the workspace you used before. Set `[workspaces] return_when_empty = false` to stay.
- **A bare `tuios attach`** goes to the session you used last.
- **`tuios new`** starts the session in the folder you run it from. Before, it used the daemon's folder.
- **New default keys:** `Ctrl+B ]` pastes a buffer, `Ctrl+B #` lists the buffers, `Ctrl+B /` opens the pane navigator and `Ctrl+B Q` labels the panes. `tuios keybinds doctor` names any clash with your own keys.
- **Shift+Up and Shift+Down** scroll only a pane on the main screen with no mouse mode. A full-screen program gets the keys.
- **Mode keys** show as a legend in the dock, not as a message.

### For scripts

- **A pane's `TERM`** is now one that this machine has a terminfo entry for. DA1 reports only what the emulator does: `62;22`, or `62;4;22` with sixel.
- **Tapes stop at the first failure.** `tape play` exits non-zero after a failed tape.
- **`tuios subscribe --types`** refuses an unknown event type.
- **Typing over a host link** into a pane that waits on a prompt needs `respond` in that host's `[hosts]` link policy.
