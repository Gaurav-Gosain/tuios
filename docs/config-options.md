# Option reference

Do not edit this file by hand. A test writes it from the option registry, the same table that `tuios list-options` prints.
To write it again, run `go test ./internal/config -run TestConfigOptionsDocMatchesRegistry -update`.

Each option is a key in `config.toml`. `tuios set-config` and the settings page change the same options.
[CONFIGURATION.md](CONFIGURATION.md) tells more about the options that need it.
The defaults are the ones on Linux. Some defaults are different on macOS.

## agents

| Option | Type | Default | Description |
|---|---|---|---|
| `agents.acp_version` | int | `0` | The ACP version a pane start-agent --protocol acp opens asks the agent for: 1, or 2, a draft of the spec. An agent that speaks only version 1 still works when 2 is asked for. The daemon reads it when it starts a protocol pane |
| `agents.answer_advance` | bool | `true` | After an answer in the agents view, move the cursor to the next agent that needs you. Off keeps the cursor on the agent you answered. |
| `agents.ask_wait_seconds` | int | `120` | Seconds ask-human waits for your answer when the agent names no timeout. The question stays after the wait. 0 uses 120 |
| `agents.card_preview` | string | `auto` | Where the task board shows the focused card's preview: beside the columns, over them, beside them on a wide screen and over them otherwise, or never. Space on a card opens and closes it. Values: `auto`, `side`, `sheet`, `off`. |
| `agents.card_preview_width` | string | empty | The width of the task board's preview panel: a number of cells, such as 70, or a share of the view, such as 40%. Empty is 40%, at least 44 and at most 96 cells. A drag on the edge of the panel changes it, and the view keeps that choice. |
| `agents.enabled` | bool | `true` | Agents, the Inbox, mail and approvals. Turn off to keep only the multiplexer. |
| `agents.fold_working` | bool | `false` | Fold the Working group of the agents view. F folds or opens a group, and the view keeps that choice. |
| `agents.list_width` | string | empty | The width of the agents view's list: a number of cells, such as 52, or a share of the view, such as 30%. Empty follows the screen. The < and > keys and a drag on the edge of the list change it, and the view keeps that choice. |
| `agents.name_hint` | string | `on` | Whether the start hint tells an agent to name its pane after its task. Off leaves that line out and tells the agent not to rename its pane or its session, so the title the program sets and the session's label stay as they are. A running agent keeps the hint it got at its start. Values: `on`, `off`. |
| `agents.reply_rows` | int | `0` | The most rows a multi-line editor grows to before it scrolls: a reply to an agent or to many, a mail draft and a new agent's task. 0 keeps each editor's own: 8 for a reply, 6 for mail, 3 for a task. An editor never takes more rows than its view has, and alt+m in it takes all of them. |
| `agents.undo_window_seconds` | int | `10` | Seconds after a dismiss, a snooze or a queued reply that u takes it back. 0 uses 10 |
| `agents.view_list` | string | `column` | How the agents view shows its list on a wide screen: a column beside the focus, a strip of chips above it, or a strip for two agents or fewer. The \ key switches it, and the view keeps that choice. Values: `column`, `strip`, `auto`. |
| `tasks.attachment_max_mib` | int | `8` | The largest file that tuios task attach puts on a card. A larger file is refused with an error that names this option. 0 uses 8 |
| `tasks.attachment_session_mib` | int | `256` | The most that the files on one session's task cards take together. 0 uses 256 |
| `tasks.attachments_per_card` | int | `20` | The most attachments one task card holds. 0 uses 20 |
| `tasks.auto_stage` | bool | `true` | Move task cards on their own when tuios sees their work move: a plan held and then approved, a fan check, a pull request. Off leaves every stage to you. |
| `tasks.machine_cap` | int | `0` | How many agents may work on this machine before Any machine starts a new one on another machine. Agents that work, agents that start, and picks not yet started count. 0 is no cap. |

| `worktree.path` | string | empty | Where new worktrees go, as a template of {{ repo_path }}, {{ repo }} and {{ branch }}, with \| slug to make one folder name. A relative path starts at repo_path. Empty puts them under $XDG_DATA_HOME/tuios/worktrees |
| `worktree.setup` | string | empty | A shell command to run in every new worktree before the agent starts, such as pnpm i. Empty runs nothing |
| `worktree.setup_async` | bool | `false` | Start the agent at once while the setup runs. A failed setup then keeps the worktree and the branch |
