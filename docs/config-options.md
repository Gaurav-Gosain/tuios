# Option reference

Do not edit this file by hand. A test writes it from the option registry, the same table that `tuios list-options` prints.
To write it again, run `go test ./internal/config -run TestConfigOptionsDocMatchesRegistry -update`.

Each option is a key in `config.toml`. `tuios set-config` and the settings page change the same options.
[CONFIGURATION.md](CONFIGURATION.md) tells more about the options that need it.
The defaults are the ones on Linux. Some defaults are different on macOS.

## agents

| Option | Type | Default | Description |

| <a id="agents.card_preview"></a>`agents.card_preview` | string | `auto` | Where the task board shows the focused card's preview: beside the columns, over them, beside them on a wide screen and over them otherwise, or never. Space on a card opens and closes it. Values: `auto`, `side`, `sheet`, `off`. |
| <a id="agents.card_preview_width"></a>`agents.card_preview_width` | string | empty | The width of the task board's preview panel: a number of cells, such as 70, or a share of the view, such as 40%. Empty is 40%, at least 44 and at most 96 cells. A drag on the edge of the panel changes it, and the view keeps that choice. |
| <a id="agents.enabled"></a>`agents.enabled` | bool | `true` | Agents, the Inbox, mail and approvals. Turn off to keep only the multiplexer. |

| <a id="agents.list_width"></a>`agents.list_width` | string | empty | The width of the agents view's list: a number of cells, such as 52, or a share of the view, such as 30%. Empty follows the screen. The < and > keys and a drag on the edge of the list change it, and the view keeps that choice. |

| <a id="agents.reply_markers"></a>`agents.reply_markers` | bool | `false` | Ask the agents that start-agent starts to write reply markers, such as [[Done]] and [[Failed: 3 tests]]. | <a id="agents.reply_rows"></a>`agents.reply_rows` | int | `0` | The most rows a multi-line editor grows to before it scrolls: a reply to an agent or to many, a mail draft and a new agent's task. 0 keeps each editor's own: 8 for a reply, 6 for mail, 3 for a task. | <a id="agents.undo_window_seconds"></a>`agents.undo_window_seconds` | int | `10` | Seconds after a dismiss, a snooze or a queued reply that u takes it back. 0 uses 10 Range: 0 to 300. |
| <a id="agents.view_list"></a>`agents.view_list` | string | `column` | How the agents view shows its list on a wide screen: a column beside the focus, a strip of chips above it, or a strip for two agents or fewer. The \ key switches it, and the view keeps that choice. Values: `column`, `strip`, `auto`. |
| <a id="tasks.attachment_max_mib"></a>`tasks.attachment_max_mib` | int | `8` | The largest file that tuios task attach puts on a card. A larger file is refused with an error that names this option. 0 uses 8 Range: 0 to 8. |
| <a id="tasks.attachment_session_mib"></a>`tasks.attachment_session_mib` | int | `256` | The most that the files on one session's task cards take together. 0 uses 256 Range: 0 to 65536. |
| <a id="tasks.attachments_per_card"></a>`tasks.attachments_per_card` | int | `20` | The most attachments one task card holds. 0 uses 20 Range: 0 to 200. |
| <a id="tasks.auto_stage"></a>`tasks.auto_stage` | bool | `true` | Move task cards on their own when tuios sees their work move: a plan held and then approved, a fan check, a pull request. Off leaves every stage to you. |
| <a id="tasks.machine_cap"></a>`tasks.machine_cap` | int | `0` | How many agents may work on this machine before Any machine starts a new one on another machine. Agents that work, agents that start, and picks not yet started count. 0 is no cap. Range: 0 to 1024. |
