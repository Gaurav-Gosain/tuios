# Default keys

Do not edit this file by hand. A test writes it from the default keymaps, the same rows that `tuios keybinds list` prints for a config that changes no key.
To write it again, run `go test ./cmd/tuios -run TestKeybindingDefaultsDocMatchesKeymaps -update`.

[KEYBINDINGS.md](KEYBINDINGS.md) tells how the keys work and how to change them.
The keys are the ones on Linux. Some keys are different on macOS.
Run `tuios keybinds list` to see the keys that your config sets.
