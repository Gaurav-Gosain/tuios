# Tape Recording

The recording guide lives on the docs site: https://tuios.gaurav.zip/docs/tape-recording

Recording is in-app: `Ctrl+B T r` starts, `Ctrl+B T s` stops. Tapes land in `~/.local/share/tuios/tapes/` and are managed with `tuios tape list`, `show`, `play`, `delete`. There is no `tape record` or `tape run` subcommand.
