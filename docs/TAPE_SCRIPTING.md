# Tape Scripting

The tape DSL reference lives on the docs site: https://tuios.gaurav.zip/docs/tape-scripting

It documents every keyword the parser accepts, timing, `tuios tape play`, `validate`, and `exec`, and what parses but does nothing. Recording happens in-app on `Ctrl+B T r`; see also [PROJECT_TAPES.md](PROJECT_TAPES.md) for `.tuios.tape` autorun and its trust boundary.
