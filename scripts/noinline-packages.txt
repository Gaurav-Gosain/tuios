# Packages built with inlining off (-gcflags=PATTERN=-l) in every build of
# cmd/tuios that ships or is measured. Inlining copies a callee into each
# caller and adds an inlining tree to the function table for each copy; in
# these packages that buys no speed anyone sees, and turning it off takes
# about 1 MB off the release binary. See docs/perf.md, "Binary size budget".
#
# A package is listed only when no hot path calls into it: drawing a frame,
# key and mouse input, the pty read loop, and the daemon's pane streams.
# scripts/goflags.sh turns this list into GOFLAGS, and every build path reads
# it through that script (or, in Go, through the same file). The internal/lint
# test TestEveryTuiosBuildReadsTheNoinlineList fails a build path that does
# not.
#
# One import path pattern per line. A # starts a comment.
